ESP IAP 控制台

系统信息

用户程序

固件上传

文件需为从 0x140000 开始的完整镜像（含分区表 B，用 build_user_app.py 生成）

留空 = 0x140000。须 4KB 对齐且 ≥ 0x140000
留空 = 写入整个文件；填数字则只写前 N 字节

固件下载

留空 = 0x140000。须 ≥ 0x140000（固定区不可下载）
留空 = 从地址读到 flash 末尾（按 flash 容量自动计算）

操作

配置区编辑

读取设备配置区 → 修改 → 写回（仅写 8KB 配置区，不影响 IAP 程序与用户程序）。 部分参数（WiFi / UART）需重启后生效。

功能开关

启动等待

进入 IAP 后等待触发源的秒数，0 表示不等待（上限 300）

WiFi 热点

最长 31 字节
8~63 字节；留空表示开放网络

UART 终端

留空或 255 = 用该端口默认引脚
留空或 255 = 用该端口默认引脚
常用: 115200 / 921600 / 1500000

I2C 从机

7 位地址，0x08~0x77

触发引脚

0 = GPIO0 (BOOT 键)；255 (0xFF) 表示未配置
引脚常态为高，接地即触发进入 IAP

APP 启动槽

IAP 启动时按启动槽序号决定加载哪个 APP 分区。槽的加载地址 / 大小 直接保存在配置区里，由你手动填写 —— IAP 不解析任何分区表。
槽位列表
可选。按 电平 % 槽数 选启动槽；255 表示关闭

启动参数

IAP 写入、用户程序读取。建议格式 key=value;key=value，最长 255 字节。
